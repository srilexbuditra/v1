# Srilex Buditra — Website Lengkap (Desain Gambar No. 4)

Website portfolio Full Stack Developer dengan tema dark navy + gold, foto profil close-up, layanan, portfolio, paket harga, formulir estimasi, WhatsApp, FAQ, alur pemesanan, dan tombol Cetak/Simpan PDF.

## Struktur
- `index.html` — halaman utama
- `style.css` — tampilan/responsive
- `script.js` — menu, estimasi harga, WhatsApp, dan print/PDF
- `assets/profile.jpg` — foto profil
- `assets/design-gambar-no-4.png` — referensi desain

## Sebelum dipublikasikan
Buka `script.js`, lalu ubah:

`const WHATSAPP_NUMBER = "6282135238350";`

menjadi nomor WhatsApp Anda dengan format internasional tanpa `+`, spasi, atau tanda `-`.

## GitHub Pages
Upload seluruh isi folder ini ke repository `srilexbuditra.github.io`. Pastikan `index.html` berada di root repository. Setelah GitHub Pages aktif, website dapat diakses online tanpa laptop harus menyala.
